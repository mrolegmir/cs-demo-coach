# v1.1 — expanded match review

This checkpoint combines the match-review extensions after v1.0. No new
database migration is required. Update API first, then the home worker for new
capture fields. Previously saved coaching prose remains unchanged.

- [Aim direction and movement](aim-movement-walkthrough.md): personal rifle
  sequences, per-shot speed and uniquely linked damage targets; capture 4 adds
  synchronized pre-damage view/eye geometry without a mechanics quality score.
- [Pre-shot movement](pre-shot-movement-walkthrough.md): half-second preparation,
  retained at the first rifle shot under capture 4's reduced-storage policy.
- [Grenade damage](grenade-damage-walkthrough.md): HE/fire enemy/team/self health
  damage and explicit unknown records, available with utility capture 1.
- [Decisions](decisions-walkthrough.md): lost-advantage review from saved death
  snapshots and bomb/post-plant timeline with objective capture 1.
- [Flash follow-up](flash-follow-up-walkthrough.md): both thrower and killer
  perspectives from stored flash intervals, with ambiguous attribution withheld.

Review remains personal, localized RU/EN and available on mobile. New observations
do not create severity grades, coach priorities, drills or longitudinal issues.
Visibility and intended target are not inferred. Shooting/movement technique
diagnoses remain unvalidated; the new tables provide reviewable evidence.

For rollout, preserve the database and existing match/brief/job counts, retain
rollback API/worker artifacts, verify HTTPS/authenticated match and progress
pages, then verify the updated worker's authenticated API read. Historical data
cannot gain missing telemetry without a fresh parse. Public showcase publishing
is separate from production deployment.
